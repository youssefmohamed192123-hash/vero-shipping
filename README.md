### 🛠️ كيفية التخصيص والتعديل (How to Customize)

#### 1. تعديل الأرقام والإحصائيات (Stats Counters)
يمكنك تعديل الأرقام مباشرة من ملف `assets/app.js` في السطور الأولى:
```javascript
const APP_CONFIG = {
  stats: {
    vehicles: 25000, // عدد السيارات المشحونة
    clients: 8500,   // عدد العملاء
    destinations: 45, // عدد الموانئ والوجهات
    experience: 12   // سنوات الخبرة
  }
};
```
أو من داخل `index.html` في خصائص `data-target="25000"`.

#### 2. ربط نظام التتبع المباشر (Tracking API / Portal)
في ملف `assets/app.js`، تجد إعدادات التتبع مهيأة وجاهزة:
```javascript
const TRACKING_CONFIG = {
  mode: 'demo', // يمكنك تغييره إلى 'api' أو 'redirect'
  apiUrl: 'https://api.veroshipping.com/v1/shipments/track',
  portalUrl: 'https://tracking.veroshipping.com/?tracking='
};
```
- إذا غيرت `mode: 'redirect'`، سيقوم الموقع بنقل المستخدم تلقائياً إلى بوابتك الحالية مع تمرير رقم التتبع في الرابط.
- إذا بقي `mode: 'demo'`، سيعرض النموذج التفاعلي الحالي المدمج بالصفحة.

#### 3. استبدال الصور (Image Placeholders)
جميع الصور تم تعليمها بتعليقات واضحة في كود `index.html`:
`<!-- REPLACE WITH YOUR CUSTOM IMAGE: ... -->`
- صورة خلفية الهيرو (سفينة نقل السيارات في الميناء).
- صورة قسم من نحن (مستودع التصدير وميناء سافانا).
- صورة فرع سلطنة عمان (ميناء صحار وصلالة).

#### 4. تعديل نصوص اللغتين العربية والإنجليزية
كل نص في الموقع موجود في كائن واحد واضح في بداية `assets/app.js`:
- نصوص الإنجليزية في `translations.en`
- نصوص العربية في `translations.ar`

### 🚀 النشر والتشغيل (Deployment)
المشروع مبني بأسلوب Single-Page فائق السرعة والخفة (Static HTML + Vanilla JS + Tailwind CSS):
- يمكنك رفعه مباشرة على أي استضافة (cPanel, Hostinger, Namecheap, Vercel, Netlify, Cloudflare Pages, Firebase Hosting, أو GitHub Pages).
- لا يتطلب أي خادم Node.js أو خادم بايثون لتشغيله في بيئة الإنتاج.
- لفتحه وتجربته محلياً، فقط انقر مرتين على `index.html` في أي متصفح!
